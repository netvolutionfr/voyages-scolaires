# Architecture Decision Records (ADR)

Ce dossier trace les décisions d'architecture et de conformité du projet.
Une décision = un fichier, numéroté, jamais modifié après acceptation
(une décision remplacée est marquée « Remplacée par ADR-NNNN » et un nouvel
ADR est créé).

Format : [MADR](https://adr.github.io/madr/) allégé — Statut, Contexte,
Décision, Conséquences.
